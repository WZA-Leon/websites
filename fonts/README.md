# WZA Sans

站点内嵌字体，基于 **Noto Sans SC** 子集生成，仅包含本站当前使用到的字符。

- 字体家族：Noto Sans SC
- 版权：© 2014-2021 Adobe，Reserved Font Name "Source"
- 许可证：SIL Open Font License 1.1
- 许可证地址：https://scripts.sil.org/OFL
- 源字体：`NotoSansSC-VF.ttf`（Google Noto 字体，OFL 1.1）

文件：

- `wza-sans-400.woff2` / `wza-sans-400.woff`：常规字重
- `wza-sans-700.woff2` / `wza-sans-700.woff`：粗体字重

子集由 `fonttools` 生成，覆盖站内 HTML、JS、CSS、Markdown、JSON 中出现过的字符。新增大量生僻字或新的语言内容时，需要重新生成子集，否则会回退到系统字体。
