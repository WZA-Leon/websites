# WZA 创想日志

一个持续生长的个人网站：博客、项目、摄影、云盘分享和若干小实验都收在这里。

## 项目目标

- 用统一的视觉语言组织不同类型的内容
- 博客文章使用 Markdown 维护，云盘分享使用静态列表维护，降低更新成本
- 在没有后端的情况下，保持页面加载和交互足够顺滑
- 让每一个页面都有自己的主题，而不是简单复制同一套模板

## 技术栈

- HTML / CSS / JavaScript
- Markdown + marked
- JSON 索引 + 静态数据文件
- 响应式布局、滚动揭示、页面加载层

## 页面结构

| 区域 | 内容 |
| --- | --- |
| 首页 | 个人介绍、兴趣领域、精选项目、精选文章 |
| 项目 | 项目目录、分类筛选、项目文档 |
| 云盘 | 网盘文件分享、提取码与失效反馈 |
| 博客 | 长文、创作记录与可复用指南 |
| 摄影 | 分类图库与作品查看器 |

## 后续计划

- 增加更多云盘分享与 Markdown 文章
- 优化移动端的阅读体验
- 继续完善暗色主题的霓虹视觉
