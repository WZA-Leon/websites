# WZA 创想日志

一个持续生长的个人网站：博客、项目、摄影、资源库和若干小实验都收在这里。

## 项目目标

- 用统一的视觉语言组织不同类型的内容
- 博客与资源库使用 Markdown 维护，降低更新成本
- 在没有后端的情况下，保持页面加载和交互足够顺滑
- 让每一个页面都有自己的主题，而不是简单复制同一套模板

## 技术栈

- HTML / CSS / JavaScript
- Markdown + marked
- JSON 索引 + 静态数据文件
- 响应式布局、滚动揭示、页面加载层

## 页面结构

| 区域 | 内容 |
| --- | --- |
| 首页 | 个人介绍、兴趣领域、精选项目、精选资源 |
| 项目 | 项目目录、分类筛选、项目文档 |
| 资源 | 可复用的指南、清单和速查表 |
| 博客 | 长文与创作记录 |
| 摄影 | 分类图库与作品查看器 |
