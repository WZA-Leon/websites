# ZADM 随机点名

ZADM（子昂点名）是一个基于 Python Tkinter 的图形化随机点名工具。

## 主要功能

- 从 JSON 文件动态加载姓名列表
- 滚动抽选与手动停止
- 已抽中名单管理
- 支持多名单配置
- 课堂互动和活动抽奖都能用

## 使用方式

```bash
python zadm.py
```

程序启动后会读取同目录下的名单配置；也可以在选择名单后开始抽选。

## 设计细节

界面尽量保持简单：一个主按钮、一个名单区域和一条状态提示。随机逻辑使用 Python 的 `random` 模块，并在每次抽选后从候选池中移除已选中的姓名，避免短时间内重复。
